## About

I'm Ali Khan, a software engineer focused on **backend development, cloud infrastructure, and distributed systems**. I enjoy understanding how systems work beneath the API: data flows, background jobs, access control, deployment processes, and failure handling.

Recently worked remotely as a **Backend Engineer at Naviko**, a Canada-based company, where I contributed to the development of its product and backend services. Outside professional work, I build tools focused on cloud automation, developer productivity, and backend architecture.

- **Cloud & infrastructure:** AWS, Docker, Linux, CI/CD, Nginx
- **Languages & other interests:** JavaScript, TypeScript, Python, applied AI

## How I Approach Engineering

- **Understand before changing:** learn the existing codebase and its constraints before implementing a feature.
- **Design for failure:** consider retries, validation, authorization, and error handling as part of the implementation.
- **Keep systems understandable:** use clear boundaries, useful documentation, and maintainable code.
- **Verify the result:** prefer reproducible setup instructions, tests, and observable behavior over claims alone.
